# Changelog

All notable changes to AgentShield are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Portfolio case study, product roadmap, repository templates, and documentation checks.
- Versioned readiness diagnostics through `agentshield doctor`.
- Privacy-safe Prometheus text exposition for point-in-time inspection.
- Deterministic sanitizer-backed parser fuzzing and an enterprise operations guide.
- Monthly security regression workflow, manual CI dispatch, and automated GitHub
  Actions update proposals.
- CodeQL Action v4 on the supported Node.js 24 runtime, pinned to an immutable commit.
- Optional content-addressed policy pinning with fail-closed SHA-256 verification.

## [0.1.0] — 2026-08-26

### Added

- Read-only Linux runtime sensor in C11.
- Deterministic risk, policy, audit, and behavioral analytics engine in C++17.
- Modern Java 17 desktop console with guided Demo Lab.
- Credential-name, resource, privilege, and access-drift visibility.
- Secure supervised execution and delegated cgroup v2 containment.
- HMAC-SHA-256 audit verification and Helix-compatible export.
- Deterministic Linux archive and Debian installer with SBOM and provenance.
- Required native, desktop, and CodeQL checks on protected `main`.
