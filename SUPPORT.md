# Support

AgentShield is currently a portfolio-quality Linux/WSL preview, not a supported
enterprise service. Use GitHub issues for reproducible defects and focused
feature proposals.

Before opening an issue:

1. Check the [platform support matrix](docs/PLATFORM_SUPPORT.md) and
   [documented limitations](README.md#security-boundaries).
2. Reproduce with synthetic data where possible.
3. Remove credential values, usernames, private paths, IP addresses, audit keys,
   and raw security telemetry.

Report suspected vulnerabilities through the private process in
[SECURITY.md](SECURITY.md), never through a public issue. There is no guaranteed
response time or service-level agreement for this preview.
