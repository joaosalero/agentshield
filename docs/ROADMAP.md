# Product roadmap

## Portfolio-complete baseline — delivered

- C11 Linux sensor, C++17 policy/risk engine, and Java 17 desktop console
- live credential-name, resource, privilege, and access-drift visibility
- deterministic allow/approval/deny policy with secure supervised execution
- authenticated local audit and verified Helix-compatible export
- guided synthetic Demo Lab and explainable behavioral advisory analytics
- Debian installer, application shortcut, icon, SBOM, provenance, and CI gates

## Enterprise foundation

- eBPF event collection for short-lived filesystem, process, and network activity
- signed policy bundles and externally anchored audit receipts
- stable configuration migration and signed update/rollback channel
- performance, soak, fuzzing, and representative behavioral evaluation corpora
- operational metrics, health diagnostics, alert routing, and support runbooks

## Multi-platform and centralized operations

- Windows ETW and macOS Endpoint Security adapters
- mutually authenticated Helix Sentinel transport
- centralized fleet inventory, policy rollout, and evidence retention
- enterprise SSO, RBAC, tenant isolation, and administrative audit
- SIEM/SOAR connectors with explicit data minimization

## Assurance and compliance

- independent penetration test and threat-model review
- documented secure development lifecycle and incident-response exercises
- release signing backed by protected CI identity
- evidence packages supporting SOC 2 and ISO 27001 control mapping

Roadmap items are directional and are not commitments or current capabilities.
